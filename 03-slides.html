Red Hat Trusted Libraries

Codename: Calunga

A system for building, verifying, and distributing Python wheels
compiled from source in a trusted build environment.

1035+ packages manylinux_2_28 Python 3.12 SLSA provenance Enterprise Contract Fromager Konflux CI

Why?

The Problem

  • PyPI wheels are pre-built binaries — you trust the maintainer's build environment
  • No SLSA provenance or attestation
  • Dependencies resolved at build time by maintainers, not you
  • SBOMs are rare or inconsistent
  • Supply chain attacks (typosquatting, account takeover) are increasing

Calunga's Answer

  • Every wheel built from source using Fromager
  • Built inside a controlled manylinux builder image (UBI8)
  • Full SLSA provenance via Tekton Chains
  • Embedded SBOMs in every wheel
  • Enterprise Contract validation before release
  • Integration tested on 6 OS targets

Build Details

  • Base: UBI8 (Red Hat Universal Base Image)
  • Policy: manylinux_2_28
  • Compiler: gcc-toolset-14
  • Cross-compilation: static clang support
  • All source tarballs verified by SHA256
  • Build time: ~45 min (8 CPU, 12Gi RAM)

Key Tools

  • Fromager — dependency resolution + source wheel builds
  • auditwheel — manylinux compliance
  • cosign — signature verification
  • cmake — C/C++ build system

How Users Consume It

pip

# pip.conf
[global]
index-url = https://<user>:<token>@\
  packages.redhat.com/\
  trusted-libraries/python/

# Then just:
pip install numpy
pip install -r requirements.txt

Verify Attestations

pip download numpy==2.3.3
unzip numpy-*.whl -d extracted
cat extracted/numpy-*.dist-info/\
  sboms/redhat.spdx.json
